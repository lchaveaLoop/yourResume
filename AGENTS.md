# Project Agent Instructions

## Completion Report Requirement

After every task is completed, proactively include a project progress report in the final response.

The report should include:

- Module progress: completed, in progress, pending, and known risks.
- Development details: what changed, which modules were affected, and why.
- Relevant file tree: the directories and files related to the task.
- File responsibilities: the feature/module role of each important changed or added file.
- Verification results: commands run and whether they passed.
- Next-step recommendation: the next module or task to continue, aligned with the current architecture.

Keep the report concise, but make it detailed enough to understand current project status and module boundaries.
